# PGtwo: Lean checks for the structure theory of pseudotopological groups, Phase A (24 November 2026)

Modules: `LeanCheck/PGTwoGeneration.lean`, `PGTwoLattice.lean`, `PGTwoReflection.lean`, `PGTwoCoreflection.lean`, and the axiom report `PGTwoAxioms.lean`. They build on the modules of the first article (`PGNullFilters.lean`, `PGGenerated.lean`; see `PG_FORMALIZATION.md`). Typechecked with Lean 4.35.0 and Mathlib (the `lean-toolchain` of this repository), one module at a time; no `sorry`; every declaration listed in `PGTwoAxioms.lean` depends only on `propext`, `Classical.choice` and `Quot.sound`. A Lean proof verifies its formal statement under its hypotheses; the correspondence with the statements of the article (`PGtwo`, Pseudotopological Groups II: Structure Theory, unpublished) was checked by the author and has not been reviewed independently. No independent build of these modules by anyone else has been made.

Setting: `G` an abelian group; filters are Mathlib filters, "finer" is `≤`, proper means `NeBot`; `F - x` is `Filter.map (· - x) F`, `F + H` is `Filter.map₂ (· + ·) F H`; a filter converges to `x` in a topology if `F ≤ 𝓝 x`. A PG is given by a null family `C` (`NullFamily`, `PGNullFilters`). Only the abstract part of the second article is formalized; the digit and two-base arguments, the examples and the arithmetic inputs are not.

## `PGTwoLattice` (Section 4: the lattice of PG convergences)
| Declaration | Statement |
|---|---|
| `nullFamily_top`, `nullFamily_bot`, `nullFamily_le_top`, `nullFamily_bot_le` | The indiscrete (all proper filters) and the discrete (`{pure 0}`) null families, and every null family lies between them. |
| `nullFamily_sInter` | Meets: the intersection of a nonempty set of null families is a null family. |
| `nullFamily_sup` | Joins: `D(⋃ 𝒩)` is the least null family containing all members of `𝒩`. |
| `hausdorff_mono`, `hausdorff_bot` | Hausdorff null families form a down-set; the discrete one is Hausdorff. |
| `exists_ultra_compl_mem` | If `s ∉ F` for a proper filter `F`, some ultrafilter finer than `F` contains `sᶜ`. |

## `PGTwoReflection` (Section 5: reflection into the topological groups)
| Declaration | Statement |
|---|---|
| `vic C`, `vic_zero_mem`, `vic_neg`, `vic_le_add` | Lemma 5.1: the vicinity filter (the sets in every null filter) has members containing `0`, is symmetric and satisfies `V + V ⊆ V`. |
| `IsNbhdFilter N`, `exists_topology`, `nhds_zero_isNbhdFilter` | The filters (members contain `0`, symmetric, halvable) are exactly the neighbourhood filters of `0` of group topologies (Mathlib `AddGroupFilterBasis`). |
| `halveFilter V`, `isNbhdFilter_halveFilter`, `le_halveFilter`, `halveFilter_le` | Definition 5.3 and Theorem 5.4: the filter of sets with a halving sequence in `V` is a neighbourhood filter, lies between `V` and every neighbourhood filter `N` with `V ≤ N`. |
| `Elig`, `IsFinest`, `exists_finest` | Theorem 5.2: there is a finest group topology in which every null filter converges to `0`; its neighbourhood filter of `0` is `halveFilter (vic C)`. |
| `reflector_univ` | Its universal property: a homomorphism into a topological group maps the null filters to filters converging to `0` iff it is continuous for the finest topology. |

## `PGTwoCoreflection` (Section 5: coreflections)
| Declaration | Statement |
|---|---|
| `le_nhds_iff_map_sub`, `KMem`, `kmem_iff` | Proposition 5.9(a): a group topology belongs to `𝒦(ξ)` (every proper filter convergent in it converges for the PG) iff its neighbourhood filter of `0` is a null filter. |
| `XiCont`, `xiCont_iff`, `isNbhdFilter_map` | A homomorphism `f` from a topological group is continuous for the PG iff `f(𝓝 0)` is null, and `f(𝓝 0)` is a neighbourhood filter of a group topology on the target (no surjectivity needed). |
| `univ_of_coarsest` | Proposition 5.9(b): if `𝒦(ξ)` has a coarsest member `t₀`, every continuous homomorphism from a topological group into the PG is continuous for `t₀`. |
| `coarsest_of_coreflection` | Lemma 5.7: a coreflection `(R, ε)` of the PG (universal property stated for topological groups of the universe of `G`) gives a coarsest member of `𝒦(ξ)`. |
| `kernel_open_of_trivial` | Proposition 5.9(c): if `pure 0` is the only halvable null filter whose members contain `0`, every continuous homomorphism from a topological group has an open kernel. |
| `finite_member_eq_pure` | Lemma 5.10: on a torsion-free group a halvable filter whose members contain `0` and that has a finite member is `pure 0`. |
| `Sn`, `CondM`, `rank_of_genUlt` | Signed `n`-fold sums and condition (M); every ultrafilter converging to `0` in the PG generated by `u` contains `Sn n A` for all `A ∈ u`, for some `n`. |
| `eligible_eq_pure`, `kernel_open_of_condM` | Theorem 5.16 (for `G = ℤ`): under (M), every halvable null filter of the PG generated by `u` whose members contain `0` is `pure 0` (symmetry is not used), and every continuous homomorphism from a topological group into that PG has an open kernel. |

Not formalized: the digit lemma behind Theorem 5.17 (strongly summable ultrafilters), the lemmas on signed powers, the two-base arguments, Theorem 5.24, the quotient and product constructions, the vicinity-filter propositions, and all examples.
